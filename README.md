# SITEE — маркетплейс цифровых товаров с привязкой к SOL

**SITEE** — маркетплейс цифровых товаров в формате Telegram Mini App: магазины цифровых товаров,
привязанные к администратору магазина, мессенджер с E2EE, эскроу-механика заказа со спорами и
арбитражем, звёзды и цифровые подарки, расчёты в SOL (кастодиальный внутренний баланс) и
Telegram Stars.

> Краткое описание (п.1 запроса): **маркетплейс с привязкой SOL** — витрина магазинов цифровых
> товаров, где все денежные потоки (аренда магазина, товары, подарки, споры) номинированы и
> исполняются в SOL через внутренний кастодиальный ledger, а «звёзды» (Telegram Stars / XTR)
> используются как вторая расчётная единица для подарков и буста магазинов.

здесь нет тулчейнов Go/Rust и нет доступа к `proxy.golang.org` и `crates.io`. Бэкенд сознательно

```bash
# бэкенд (Go, без внешних зависимостей)
cd backend && go build ./... && go test ./... && go run ./cmd/siteed

# крипто-ядро (Rust, без внешних крейтов)
cd crypto-core && cargo test && cargo run --release -- --listen 127.0.0.1:8091
```

## Быстрый старт (живой прототип прямо сейчас)

Вариант A — только фронтенд + preview-сервер (не требует Go/Rust):

```bash
cd tools/preview && npm install --omit=dev && npm start     # http://0.0.0.0:8080
```

Откроется Telegram Mini App: вход/регистрация с логотипом, выбор страны и города, двойной 2FA
(Google Authenticator), лента магазинов с поиском, карточки с обложкой/рейтингом/коронкой,
нижняя панель «Магазины · Чаты · Обмен · Профиль», чат с админом магазина (E2EE, AES-256-GCM
через WebCrypto), заказ со статусами и эскроу, спор с маскировкой сторон и приглашением админа,
обменник Stars ⇄ SOL, админ-панель (подарки, аренда, споры).

Демо-доступы (создаются автоматически при старте preview-сервера):

| Роль | Логин | Пароль | TOTP |
|---|---|---|---|
| Покупатель | `buyer@sitee.dev` | `Buyer#2026` | секрет в профиле |
| Админ магазина (владелец шопa) | `shop@sitee.dev` | `Shop#2026` | — |
| Админ платформы / арбитр | `admin@sitee.dev` | `Admin#2026` | — |

Вариант B — полный прод-стенд: `deploy/docker-compose.yml` (Go-бэкенд + Rust crypto-core +
PostgreSQL + Redis + MinIO + nginx). См. `docs/deploy.md`.

## Стек (п.3 запроса: Go, Rust)

* **Go** — `backend/`: HTTP/REST, WebSocket-хаб, доменная логика (магазины, аренда, заказы,
  эскроу-ledger, споры, отзывы, звёзды, подарки, админка), интеграция с Solana-сканером и
  Telegram Bot/Stars API.
* **Rust** — `crypto-core/`: всё криптографическое и «горячее» — AES-256-GCM envelope-шифрование
  данных в БД, HKDF/PBKDF2/HMAC, TOTP, генерация/хранение ключей и Ed25519-подпись Solana-транзакций,
  движок rate-limit и анти-фрод-скоринг. Go вызывает его по внутреннему HTTP/UNIX-сокету, а при
  отсутствии (`CRYPTO_CORE_URL` не задан) работает встроенный Go-fallback на `crypto/*` — тот же
  формат ciphertext, поэтому данные переносимы.
* **Фронтенд** — Telegram Mini App (Web App): HTML/CSS/JS-модули без сборщика + Telegram WebApp SDK
  (`telegram-web-app.js`), WebCrypto для E2EE.

Подробности — `docs/TZ.md` и `docs/architecture.md`.
