## 7. Как запустить

```bash
# Вариант A — прототип без Go/Rust (нужен только Node ≥ 20)
cd tools/preview && npm run start:demo      # http://0.0.0.0:8080

# Вариант B — полноценный бэкенд
cd backend && go build ./... && go run ./cmd/siteed
cd crypto-core && cargo test && cargo run --release -- --listen 127.0.0.1:8091

# Тесты
node tools/preview/smoke.mjs                # только против свежего сервера
node tools/fe-test/run.mjs
python3 tools/contract_check.py
```

Демо-доступы (создаются при старте): `admin@sitee.dev / Admin#2026`,
`buyer@sitee.dev / Buyer#2026`, `arbiter@sitee.dev / Arbiter#2026`,
`shop@sitee.dev / Shop#2026`. Коды 2FA и backup-коды — в `GET /api/v1/dev/credentials`.
